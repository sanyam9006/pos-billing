# Prototypes

These are static HTML mockups created during the initial design phase.

They are **not connected** to the actual POS backend and exist solely as design references.

- `supermart_pos.html` — POS billing screen mockup
- `supermart_admin.html` — Admin panel mockup
- `app.html` — Combined app layout mockup

The actual application lives in `/client` (React/Vite frontend) and `/server` (Express API).
