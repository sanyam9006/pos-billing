🚀 Quick 3-Step Setup for Windows Laptop

Step 1 Install Node.js (Only required once)

Before running the POS, your Windows laptop must have Node.js installed:

🌐 Download Node.js from nodejs.org

Click the big green button "LTS (Recommended)", download it, and click Next ➔ Next ➔ Finish.

Step 2 Extract the ZIP File

Right-click the HouseOfSadaya-POS.zip file and choose Extract All... to your Desktop.

Step 3 Double-Click START-POS.bat

Inside the extracted folder, double-click START-POS.bat.

• On first run, it will automatically install required packages in 1–2 minutes.
• Your browser will automatically open: http://localhost:5173

⚠️ If Windows displays "Open File - Security Warning (Unknown Publisher)":
Windows shows this for any script downloaded from WhatsApp/Drive/email. Simply uncheck "Always ask before opening this file", and click Run. It is 100% safe.
💡 Tip for Everyday Convenience: Right-click START-POS.bat ➔ Send to ➔ Desktop (create shortcut). Every morning, just double-click that desktop icon to open your store POS!

🛍️ Store Modules & Operations

🧾 1. Billing & Scanning

Plug in any USB barcode scanner. Scan tags directly into the search box. Accept Cash, UPI, or Card.

⚡ 2. 1-Click Matrix Variants

Generate S, M, L, XL sizes in multiple colors in 1 click with guaranteed collision-free unique EAN-13 barcodes.

🏷️ 3. Real Barcode Tags

Print scannable price tags for 50x25mm and 38x25mm rolls, or standard A4 sheets with store name and MRP.

💎 4. Garment Rentals

Track bridal lehengas and occasion sarees on rent. Collect security deposits and compute late return fees.

🪡 5. Tailoring Orders

Record blouse/suit measurements, trial dates, fabric delivery dates, and advance tailoring payments.

📊 6. Reports & Analytics

View daily X/Z-Reports, hourly rush trends, profit margins, and itemized sales timestamps.

🌙 Closing the Day

At store closing time, go to Reports ➔ Z-Report to verify cash in drawer and daily sales, then double-click STOP-POS.bat or close the terminal window to turn off background services.
